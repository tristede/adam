# Portfolio d'Adam — instructions pour les agents

**Lire `CLAUDE.md` en entier avant toute modification** : c'est la source de vérité (règles,
architecture, décisions prises, état du contenu, ce qui reste à faire). Ce fichier n'en est que
le rappel pour les agents qui lisent `AGENTS.md`.

Les 5 points à ne jamais oublier :

1. **Ne publier que sur demande d'Adam**, après `git fetch` (rien de plus récent en ligne) et un scan
   du diff : dépôt public, **jamais de nom de famille ni d'e-mail perso**.
2. **Ne pas toucher à la DA** (bleu nuit étoilé, texte manuscrit qui se décrypte) sans demander.
3. **Positionnement « créatif volatile / enfant d'internet »**, pas « créateur de contenu ».
4. **Descriptions courtes : mots-clés, 62 caractères max, sans répéter le titre.** Ne rien inventer :
   demander les faits manquants.
5. **Incrémenter `?v=N`** de `style.css` / `script.js` dans *tous* les HTML (404 compris) à chaque
   modification de ces fichiers ; `data.json` garde le format d'écriture de l'admin (2 espaces, UTF-8).
